# MagicGrimoire — ESO Build Launcher

MagicGrimoire — це мій кастомний лаунчер для The Elder Scrolls Online.

## 🔥 Можливості
- Відображення білдів із `builds.json`
- Інформація про клас, роль, CP та сети
- Показ картинок персонажів
- Запуск ESO / Steam з параметрами
- Майбутнє: GUI-вікно (desktop app)
